# Zielona Przestrzeń — Ogrody z pasją

Demonstracyjna strona HTML/CSS/JavaScript przygotowana do analizy przez uczennicę w ramach nauki do egzaminu zawodowego.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Strona nie wymaga serwera ani instalowania bibliotek.

## Pliki

- `index.html` — struktura strony i treść
- `style.css` — wygląd, responsywność i układ
- `script.js` — menu mobilne, slider hero i obsługa interakcji
- `images/` — lokalne grafiki strony

## Ważne

Wersja korzysta z lokalnych grafik. Dane kontaktowe są przykładowe.


### Efekty JavaScript
- automatyczny slider hero z przyciskami i kropkami,
- menu mobilne,
- animowane pojawianie się sekcji i kart podczas przewijania (`IntersectionObserver`),
- interaktywny wybór miesiąca w kalendarzu (obsługa kliknięcia oraz klawiatury).
